# ml_start_hw3

Домашняя работа по задаче прогнозирования оттока клиентов телеком-компании.

В проекте решается задача бинарной классификации: по данным о клиенте, его тарифе, способе оплаты, сроке обслуживания и подключенных услугах нужно предсказать, уйдет ли клиент в отток.

## Файлы

- `main.ipynb` - основной ноутбук с анализом данных, обучением моделей и итоговыми выводами.
- `отчет.pdf` - PDF-отчет по выполненной работе.

## Что сделано

- Проведен первичный анализ данных и обработка признака `TotalCharges`.
- Выполнен EDA: изучены распределения, дисбаланс классов и связь оттока с ключевыми признаками.
- Подготовлены признаки: масштабирование числовых признаков, One-Hot Encoding категориальных признаков, feature engineering.
- Обучены и сравнены модели:
  - Logistic Regression;
  - Random Forest;
  - CatBoost;
  - MLP на PyTorch.
- Для моделей проведены подбор гиперпараметров и 5-fold stratified cross-validation.
- Проанализированы ROC-AUC, Precision, Recall, F1-score и confusion matrix.
- Выполнен подбор порога классификации по out-of-fold предсказаниям.
- Проведен анализ важности признаков CatBoost и бизнес-интерпретация retention-кампании.

## Основные результаты

По результатам кросс-валидации лучший ROC-AUC показал CatBoost:

| Модель | ROC-AUC CV |
| --- | ---: |
| Logistic Regression | 0.848 |
| Random Forest | 0.846 |
| CatBoost | 0.851 |
| MLP | 0.847 |

На тестовой выборке результаты моделей оказались близкими:

| Модель | ROC-AUC Test |
| --- | ---: |
| Logistic Regression | 0.846 |
| Random Forest | 0.844 |
| CatBoost | 0.846 |
| MLP | 0.844 |

После подбора порога классификации основной моделью выбран CatBoost с порогом `0.34`.

Итоговые метрики CatBoost на тестовой выборке при этом пороге:

| Metric | Value |
| --- | ---: |
| Precision | 0.562 |
| Recall | 0.727 |
| F1-score | 0.634 |
| ROC-AUC | 0.846 |

## Как запустить

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Открыть ноутбук:

```bash
jupyter notebook main.ipynb
```

Ноутбук использует датасет Telco Customer Churn. Для повторного запуска файл `WA_Fn-UseC_-Telco-Customer-Churn.csv` должен находиться в корне проекта рядом с `main.ipynb`.

## Вывод

CatBoost лучше всего ранжирует клиентов по вероятности оттока, а настройка порога позволяет увеличить Recall и сделать модель полезной для формирования целевой аудитории retention-кампаний. Экономический эффект такой кампании зависит от стоимости удержания, стоимости потери клиента и эффективности предложения.
